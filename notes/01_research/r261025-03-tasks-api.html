概要とエンドポイント

Google Tasks API は、Google Tasks のコンテンツとメタデータを、プログラムから検索・読み取り・更新するための REST API。自社サービスを Google Tasks につなぐ使い方と、Apps Script での自動化 (メールや文書の操作をきっかけにタスクを作る、外部システムのデータでリストを定期更新する) が、公式の概要に挙がっている。

ベース URL は https://tasks.googleapis.com。リソースは tasklists (リスト) と tasks (タスク) の 2 つ。

tasklists

メソッドHTTPパス内容
listGET/tasks/v1/users/@me/listsリストの一覧
getGET/tasks/v1/users/@me/lists/{tasklist}指定のリストを取得
insertPOST/tasks/v1/users/@me/listsリストを作成
patchPATCH/tasks/v1/users/@me/lists/{tasklist}部分更新
updatePUT/tasks/v1/users/@me/lists/{tasklist}更新
deleteDELETE/tasks/v1/users/@me/lists/{tasklist}リストを削除

tasks

メソッドHTTPパス内容
listGET/tasks/v1/lists/{tasklist}/tasksタスクの一覧
getGET/tasks/v1/lists/{tasklist}/tasks/{task}指定のタスクを取得
insertPOST/tasks/v1/lists/{tasklist}/tasksタスクを作成
patchPATCH/tasks/v1/lists/{tasklist}/tasks/{task}部分更新
updatePUT/tasks/v1/lists/{tasklist}/tasks/{task}更新
deleteDELETE/tasks/v1/lists/{tasklist}/tasks/{task}タスクを削除
movePOST/tasks/v1/lists/{tasklist}/tasks/{task}/move別の位置 (別のリストを含む) へ移動
clearPOST/tasks/v1/lists/{tasklist}/clear完了済みのタスクをクリア (非表示にする)

出典: Google Tasks API の概要 ・ Tasks API REST リファレンス (Google for Developers)

Task と TaskList のフィールド

Task

フィールド型読み取り専用内容
id / etagstring明記なし識別子と ETag
titlestringいいえタスク名。最大 1024 文字
notesstringいいえメモ。最大 8192 文字。Google ドキュメントから割り当てられたタスクには設定できない
statusstringいいえneedsAction または completed
dueRFC 3339いいえ予定日 (下の IMPORTANT を参照)
completedRFC 3339明記なし完了日時。未完了なら省略される
deletedbooleanいいえ削除済みか。既定 false。割り当てられたタスクでは読み取り専用
hiddenbooleanはいリストをクリアした時点で完了していたタスクが true
parentstringはい親タスクの ID。トップレベルでは省略される。変更は move
positionstringはい同じ階層での並び順。辞書順で比べる。変更は move
links[]object[]はい関連リンク (type・description・link)。type の例は email・generic・chat_message・keep_note
webViewLinkstringはいWeb UI で開く絶対 URL
assignmentInfoobjectはい割り当てられたタスクの出所 (linkToTask・surfaceType・driveResourceInfo・spaceInfo)
updated / selfLink / kindstringはい最終更新日時、操作用の URL、tasks#task
due は期限ではなく、そのタスクを行う予定日 (カレンダーに表示される日)。RFC 3339 の形だが、設定時に時刻は捨てられ日付だけが残る。公式に「API では予定の時刻を読み書きできない」とある。時刻つきの期限を前提に設計すると誤る。

TaskList

  • id・etag・title (最大 1024 文字)・updated・selfLink・kind (tasks#taskList)。updated・selfLink・kind は出力専用

一覧・移動と上限

tasks.list の主なパラメータ

パラメータ既定・上限内容
maxResults既定 20、上限 1001 ページの件数
pageToken-前回の nextPageToken を渡す
showCompleted既定 true完了済みを含めるか
showHidden既定 false非表示を含めるか
showDeleted既定 false削除済みを含めるか
showAssigned既定 false自分に割り当てられたタスク (Docs・Chat のスペース由来) を含めるか
dueMin / dueMax指定なしなら絞らない予定日の範囲 (RFC 3339)
completedMin / completedMax指定なしなら絞らない完了日の範囲
updatedMin指定なしなら絞らない最終更新日時の下限
Web UI やモバイルアプリで完了したタスクは、showHidden も true にしないと一覧に出ない。「完了済みが取れない」ときは、まずここを疑う。

tasks.move

  • parent (新しい親。省略でトップレベル)・previous (直前の兄弟。省略で先頭)・destinationTasklist (移動先のリスト。省略で同じリスト内) の 3 つを、クエリで渡す。リクエストボディは空
  • 親にできるのは、同じリストにあり、非表示でないタスク。割り当てタスクと繰り返しタスクは、親にも子にもできない
  • 完了済みで非表示のタスクは入れ子にできず、位置 0 にしか移せない (parent と previous を空にする)
  • 繰り返しタスクは、リストをまたぐ移動に未対応

上限

項目上限出典
1 ユーザーのタスクリスト数2,000.NET クライアントのリファレンス
1 ユーザー・1 リストあたりの非表示でないタスク数20,000tasks.list のリファレンス
1 ユーザーの全タスク数100,000tasks.list のリファレンス
1 タスクあたりのサブタスク数2,000tasks.move のリファレンス

リストの上限 2,000 は、公式の REST リファレンスのページには見つからず、Google の .NET クライアントライブラリのリファレンス (googleapis.dev) の TasklistsResource に「A user can have up to 2000 lists at a time.」とある。

出典: tasks.list ・ tasks.move (Google for Developers) ・ Google.Apis.Tasks.v1 (.NET クライアントのリファレンス)

スコープとクォータ

スコープ

スコープ (https://www.googleapis.com/auth/ 以下)内容
tasksすべてのタスクの作成・編集・整理・削除
tasks.readonlyタスクの閲覧のみ
  • 公式は、できるだけ範囲の狭いスコープを選ぶよう求めている
  • tasks.move は tasks だけを要求する。tasks.list は tasks と tasks.readonly のどちらでもよい
  • 公開アプリで該当するスコープを使うときは、アプリの検証が要る
各スコープが sensitive か non-sensitive かは、公式の Tasks のスコープのページに書かれていなかった。Cloud Console の Data Access で見る形で、静的な一覧表は見つからなかった。非公式の情報にも、区分を示すページは見つからなかった。

探した範囲: Tasks API のスコープのページ、Sensitive scope verification。後者は、Calendar の調査で、スコープごとの区分表が無いことを確かめたページ。

出典: Tasks API のスコープ ・ Sensitive scope verification (Google for Developers)

クォータ

  • 1 日 50,000 クエリ (courtesy の上限)
  • プロジェクトごとに異なる。引き上げは Cloud Console の「Quotas & System Limits」から申請できるが、承認は保証されず、大幅な増加は時間がかかることがある
  • サービスアカウントの呼び出しは、単一のアカウントとして扱われる
  • 1 分あたりの上限、エラーの種類と対処は、公式のこのページに書かれていなかった

探した範囲: 上のページと、毎分の上限・429 の検索。他の API (Health API・Admin SDK 等) の毎分の値は出たが、Tasks 固有の値を示す公式・非公式の情報は見つからなかった。

出典: Tasks API の割り当てと使用量上限 (Google for Developers)
